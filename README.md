# HexTask

Organizador de tarefas do dia a dia feito com HTML, CSS e JavaScript.

A ideia é ter um quadro simples para anotar o que precisa ser feito (em casa, no trabalho, nos estudos, no mercado, na saúde ou em outras coisas) e acompanhar o que já foi concluído, sem perder nada ao fechar o navegador.

## Funcionalidades

- Adicionar tarefas pelo botão ou apertando **Enter**
- Escolher uma **categoria** para cada tarefa (Casa, Trabalho, Estudos, Mercado, Saúde, Outros), com etiqueta colorida
- Definir a **prioridade** (alta, média ou baixa); as mais importantes ficam sempre no topo de cada coluna
- Quadro com 3 colunas: **A fazer**, **Fazendo** e **Feito**
- Clicar na tarefa para avançar de coluna, ou arrastar e soltar onde quiser
- Marcar como concluída direto pelo **círculo** do cartão
- **Editar** o texto de uma tarefa pelo lápis ✎
- Excluir uma tarefa no botão **X** ou limpar todas as concluídas de uma vez
- Painel com o **progresso do dia** (porcentagem e barra) e a quantidade de tarefas por categoria
- **Filtrar** as tarefas por categoria
- Saudação com a data e o horário do computador
- Tema **claro** e **escuro**
- Tarefas e tema ficam **salvos no navegador** (`localStorage`)
- **Acessibilidade**: HTML semântico, labels, textos alternativos, uso pelo teclado (Tab e Enter) e bom contraste nos dois temas

## Como usar no seu computador

1. Baixe ou clone o repositório:
   ```
   git clone https://github.com/cadu-ventura/hextask.git
   ```
2. Abra o arquivo `index.html` no navegador.

## Estrutura

```
index.html        → estrutura da página
css/style.css     → estilo da página (cores dos temas em variáveis)
js/script.js      → funcionamento da lista
assets/img/       → logo
```
